# 밤의 생존자 (Night Survivor)

뱀파이어 서바이버 스타일의 브라우저 액션 로그라이트 게임입니다. 공격은 자동이고, 플레이어는 이동만 합니다. 몰려오는 적을 피하며 경험치 보석을 모아 레벨업하고, 무기와 패시브를 조합해 10분간 살아남으면 승리합니다.

바로 플레이: https://shngeunwoo.github.io/survivor-rush/

`main` 브랜치에 푸시하면 GitHub Actions가 빌드해서 `gh-pages` 브랜치로 자동 배포합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:4317
npm run build    # dist/ 에 정적 빌드
```

## 조작

- 이동: `WASD` / 방향키 (모바일·마우스는 화면 드래그로 가상 조이스틱)
- 레벨업 선택: 클릭 또는 `1` `2` `3`, 새로고침 `R`
- 일시정지: `Esc` / `P` (탭을 벗어나면 자동 일시정지)

## 콘텐츠

- 캐릭터 4명: 기사 레온(채찍, 체력·방어), 마법사 아리아(지팡이, 쿨다운·공격력), 사냥꾼 카이(단검, 이동 속도), 북방 전사 브론(도끼, 체력·공격력)
- 무기 8종 (각 8레벨), 패시브 10종
- 무기 진화: 무기 8레벨 + 짝 패시브 보유 상태에서 보물 상자를 열면 진화
  - 마법 지팡이 + 쿨다운 → 천벌의 홀 / 성수 결계 + 최대 체력 → 영혼 흡수
  - 수호 단검 + 공격 범위 → 천상의 칼날 / 천둥 반지 + 공격력 → 뇌신의 분노
  - 가죽 채찍 + 체력 재생 → 피의 채찍 / 화염병 + 방어력 → 지옥불
  - 전투 도끼 + 행운의 클로버 → 죽음의 나선 / 은빛 십자가 + 복제의 거울 → 천상의 십자가
- 공명(무기 시너지): 두 무기를 모두 8레벨로 올리면 자동 발동
  - 지팡이 + 천둥 → 뇌전 마탄 / 결계 + 화염병 → 연옥 / 단검 + 채찍 → 칼날 폭풍 / 도끼 + 십자가 → 성전
- 유물 합성: 짝이 되는 패시브 두 개를 최대 레벨로 올리면 레벨업·상자에서 유물로 합성
  - 광전사의 인장, 시간술사의 모래시계, 불사조의 심장, 질풍의 갑옷, 별의 나침반
- 초월: 만렙 무기를 레벨업 선택지에서 추가 강화 (회당 피해량 +6%, 최대 5회)
- 타이틀의 조합 도감에서 모든 진화·공명·유물 레시피 확인
- 적 7종: 박쥐, 좀비, 해골, 유령, 마녀(원거리), 골렘(엘리트·40초마다·상자), 죽음의 사신(보스·3/6/9분)
- 1분마다 포위 이벤트, 치명타, 넉백, 피격 무적 시간
- 골드 수집 → 상점에서 영구 강화 8종(힘·체력·민첩·자력·성장·탐욕·변덕·부활)
- 픽셀 아트 스프라이트, 조명/그림자, 파티클, 화면 흔들림
- 효과음 + 강도에 따라 변하는 배경 음악(Web Audio), 결과 화면의 무기별 피해량 통계
- 골드·영구 강화·최고 기록은 로컬에 저장

## 구조

- `src/game.ts` — 게임 루프, 스폰, 무기·진화, 충돌(공간 해시 그리드), 조명 포함 캤버스 렌더링
- `src/sprites.ts` — 문자열 그리드 기반 픽셀 아트 스프라이트와 아이콘
- `src/upgrades.ts` — 무기/패시브/공명/유물/캐릭터/영구 강화 정의와 레벨업 선택지
- `src/audio.ts` — 효과음과 시퀀서 배경 음악
- `src/main.ts`, `src/style.css` — HUD와 타이틀/캐릭터 선택/상점/레벨업/상자/일시정지/결과 화면
