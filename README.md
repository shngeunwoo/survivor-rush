# 밤의 생존자 (Night Survivor)

뱀파이어 서바이버 스타일의 브라우저 액션 로그라이트 게임입니다. 공격은 자동이고, 플레이어는 이동만 합니다. 몰려오는 적을 피하며 경험치 보석을 모아 레벨업하고, 무기와 패시브를 조합해 10분간 살아남으면 승리합니다.

바로 플레이: https://shngeunwoo.github.io/survivor-rush/

`main` 브랜치에 푸시하면 GitHub Actions가 빌드해서 `gh-pages` 브랜치로 자동 배포합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:4317
npm run build    # dist/ 에 정적 빌드
```

## 조작

- 이동: `WASD` / 방향키 (모바일·마우스는 화면 드래그로 가상 조이스틱)
- 레벨업 선택: 클릭 또는 `1` `2` `3`
- 일시정지: `Esc` / `P`

## 콘텐츠

- 무기 6종 (각 8레벨): 마법 지팡이, 성수 결계, 수호 단검, 천둥 반지, 가죽 채찍, 화염병
- 패시브 7종 (각 5레벨): 공격력, 쿨다운, 이동 속도, 최대 체력, 자석 범위, 체력 재생, 공격 범위
- 적 6종: 박쥐, 좀비, 해골, 유령, 골렘(엘리트, 45초마다), 죽음의 사신(보스, 3·6·9분)
- 1분마다 박쥐 떼 포위 이벤트, 보스 처치 시 보물 상자(레벨업 2회)
- 회복 닭다리·자석 드롭, 최고 기록 로컬 저장, 효과음(Web Audio)

## 구조

- `src/game.ts` — 게임 루프, 스폰, 무기, 충돌(공간 해시 그리드), 캔버스 렌더링
- `src/upgrades.ts` — 무기/패시브 정의와 레벨업 선택지
- `src/audio.ts` — 오실레이터 기반 효과음
- `src/main.ts`, `src/style.css` — HUD와 타이틀/레벨업/일시정지/결과 화면
